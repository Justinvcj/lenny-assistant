# Independent Review — Phases P1 to P6

Reviewer: Claude Code (Opus 4.7), strict read-only pass.
Date: 2026-10-11.
Scope: P1 scaffold, P2 DB/sessions, P3 ingest/retrieval, P4 agent (router/prompts/verify/orchestrator/chat), P5 chat UI, P6 Ship 30 skill. P7 (artifact viewer) is already present in the tree and is NOT in scope here.

## 1. Verdict (5 lines)

The core pipeline is **NOT sound as built** — one BLOCKER and several HIGH issues.
The Claude Agent SDK path is wired with a hallucinated API (no `run_agent` export, wrong `ClaudeSDKClient` init, raw funcs passed as `tools=`) and ALWAYS falls through to the degraded fallback, so decision D3 (locked-down SDK agent + narrowed MCP tool menu) is unenforced in reality.
Retrieval, grounding, citation verification, intent routing, and the Ship 30 pipeline are implemented, unit-tested, and in good shape — those are the parts you can keep.
Tests collect (307) and the pure-logic subset (147) + non-DB RAG subset (99) + DB-mocked subset (61) all pass; nothing was executed against the live stack because Docker services were not running at review time.
Fix the SDK orchestration (rewrite it to match the spike, mirror `claude_agent_sdk` API) and the few HIGHs below, then move on.

## 4. Checklist A–L (one line each)

- **A. Anti-shallow sweep** — PASS. One `NotImplementedError` in `anthropic_provider.embed` (correct, Anthropic has no embed API). One honest "placeholder" log line in `generate_ship30_essay` degraded branch. No `except: pass`, no `assert True`, no `TODO`/`FIXME` in `backend/app/`.
- **B. Hallucinated APIs** — **FAIL** (see F1). `claude_agent_sdk.run_agent` doesn't exist; `ClaudeSDKClient(base_url=…, api_key=…, model=…)` is wrong. pgvector, SQLAlchemy, Alembic, pydantic-settings, httpx, Ollama `/api/embed` payload all look correct; react-markdown + dompurify imports verified.
- **C. Ingestion & retrieval** — PARTIAL. Idempotent by `content_hash` (good), prefixes `search_document:`/`search_query:` applied (good), cosine similarity = `1 - cosine_distance` (correct), HNSW index present, `RETRIEVAL_MIN_SCORE` enforced at the chat layer (immediate refusal, no LLM call — good). Pre-insert dim verification is missing (F8). start/end char offsets look computed from `turn_start_char + sentence_offset_within_turn` — plausible, not spot-checked against real transcripts (UNVERIFIED without data/).
- **D. Agent design vs SPEC** — **FAIL** (F1, F2, F3, F4, F5). Code never actually locks the SDK down because the SDK path never runs.
- **E. Grounding & citations** — PASS for code. Citations are built from DB-provided retrieval rows via `resolve_citations`, invalid `[S#]` are stripped, zero-valid triggers one retry then refusal (chat.py:225-229), refusal path is **zero-LLM** (chat.py:136-174 confirmed). "Do not reverse cause and effect" clause present (prompts.py:27). Untrusted-source delimiters present. Follow-up query rewrite exists. Adversarial attempts not run live.
- **F. Router** — PASS. Deterministic rules, inquiry-about-essays carve-out, negation guards, multi-turn history support, 9 unit tests. "Essay" in "did someone talk about essays?" correctly stays QA via `RE_INQUIRY_ABOUT_ESSAYS`.
- **G. Ship 30 skill** — PARTIAL. Validator is real code with its own tests (4 top-level + unit). Section-by-section generation yes; one repair pass yes; `R_LENGTH` is deliberately not repaired (F11). Rules are `DRAFT-UNVERIFIED` (F10). Deterministic fallback in `chat.py:239-271` is good. Essay word count not measured against a real run (UNVERIFIED).
- **H. API & database** — PASS. Schema matches docs/architecture.md §6, Alembic migration is a single safe `IF NOT EXISTS`-friendly file, error envelope consistent, CORS driven by `cors_origins`, cascade delete on sessions→messages/artifacts via FK ON DELETE CASCADE. Transaction: user turn is committed before pipeline; assistant turn committed at the end — a pipeline exception mid-way leaves the user turn stored without a reply (acceptable, lets a retry succeed).
- **I. Frontend** — PARTIAL (not run). No `rehype-raw`, no `dangerouslySetInnerHTML` in src; good. Markdown rendered via react-markdown with a link component that strips `javascript:` and forces `rel="noopener noreferrer"`. Artifact iframe uses `sandbox=""` + CSP `default-src 'none'` as spec requires. See F6 (title not HTML-escaped) and F13 (markdown heuristic).
- **J. Security basics** — PASS. `.gitignore` covers `.env`, `data/`, `notes/`, `.venv/`, `dist/`. `git ls-files` finds no transcripts, no `.env`, no key-like filenames. Postgres bound to `127.0.0.1:5432` only. Dockerfile uses non-root `appuser`. DB healthcheck present.
- **K. Test quality** — PARTIAL. Verify/router/prompts/ship30 tests exercise real logic (not vacuous). Ingest tests use `AsyncMock(spec=AsyncSession)` which triggers "coroutine never awaited" warnings — pass but warn. Orchestrator tests mock around the actual SDK call (F3). Missing high-value tests: (1) real init-tool-list assertion for SDK; (2) poisoned-chunk prompt-injection test; (3) end-to-end chat flow with FakeLLMProvider+FakeEmbeddingsClient (hits the chat router from TestClient); (4) ingestion dim mismatch test; (5) artifact title HTML-escape test.

1. **F1 — Rewrite `_run_with_sdk` to the real `claude-agent-sdk` API** (match `spike/sdk_test.py`). Mandatory; everything else about the agent layer is moot until this works.

3. **F3 — Add a real "init tool list" test** that constructs the orchestrator's `ClaudeAgentOptions` and asserts allowed/disallowed tool lists match spec.
4. **F5 — Switch env var to `ANTHROPIC_AUTH_TOKEN`** per SPEC §2 and the spike.
5. **F10 — Create `notes/ship30_source.md`** from the assignment-linked Ship 30 reference and remove `DRAFT-UNVERIFIED` labels (or revise rules to the sourced ones).
6. **F6 — HTML-escape artifact title** before interpolation in `wrapHtmlDocument`.
7. **F8 — Verify embedding dimension pre-insert** in `ingest_document` (raise clean error, not DB NOT NULL violation).
8. **F11 — Tune Ship 30 outline word budgets** to hit mid-1,200s reliably, or add a one-shot length-expand repair.
9. **F13 — Trust server-set artifact `type`** in `ArtifactPanel` instead of sniffing for `<`.
